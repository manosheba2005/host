# وصلة — React + Next.js

استخدمت هذا المشروع واجهة React وNext.js App Router للواجهة وواجهات الـAPI، مع SQLite محلية لحفظ الحسابات والروابط والزيارات والضغطات.

## التشغيل

من PowerShell داخل مجلد المشروع:

```powershell
Copy-Item .env.example .env.local
# عدّل .env.local وضع كلمة مرور فريدة لا تقل عن 16 حرفًا ورقم المحفظة الخاصة بك
npm install
npm run dev
```

افتح `http://localhost:3001` (اختير المنفذ 3001 لتجنب تعارض المنفذ 3000 على الجهاز). للبناء والتشغيل الإنتاجي المحلي: `npm run build` ثم `npm run start`.

في التشغيل الأول يجب ضبط `WASLA_ADMIN_EMAIL` و`WASLA_ADMIN_PASSWORD` في `.env.local`. لا توجد كلمة مرور افتراضية في الشيفرة؛ التطبيق يرفض إنشاء حساب المالك إذا لم تُضبط كلمة مرور فريدة بطول 16 حرفًا على الأقل. ملف `.env.local` وقاعدة البيانات مستثنيان من Git. البيانات تحفظ في `wasla.sqlite` بجوار المشروع، أو في مجلد `WASLA_DATA_DIR` عند ضبطه.

## ما يعمل

- التصميم المرفق من Figma Make للصفحة التسويقية، لوحة العميل، لوحة المالك، والصفحة العامة.
- إنشاء الحساب وتسجيل الدخول، مدة تجربة 30 يومًا، وتحديث اسم العميل ورابطه ونبذته.
- إضافة وتعديل وحذف وتفعيل/إخفاء وترتيب الروابط، مع قياس زيارات الصفحة وضغطات الروابط.
- معاينة الصفحة العامة، ورمز QR، وتنزيله ونسخ رابط الصفحة.
- لوحة المالك للبحث والفلترة وإدارة العملاء، مع إشعار بطلبات فودافون كاش ومراجعتها بالموافقة أو الرفض.
- رسوم لوحة العميل مبنية على سجل الزيارات، ورسوم الإدارة على تواريخ إنشاء الحسابات.

## حدود النسخة

الدفع عبر فودافون كاش هنا يدوي: العميل يحوّل ٩٩ جنيهًا إلى 01080656762، ثم يرسل رقم المحفظة المُرسِلة (ومرجع العملية اختياريًا). يراجع المالك التحويل في تطبيق/كشف المحفظة ويوافق أو يرفض من تبويب الاشتراكات. النظام لا يتصل بفودافون ولا يتحقق من التحويل تلقائيًا. يمكن تغيير رقم الاستقبال بتعيين WASLA_VODAFONE_CASH_NUMBER قبل تشغيل التطبيق. خدمة QR الحالية خارجية، لذا توليد الصورة يحتاج إنترنت. للنشر العام يلزم HTTPS واستضافة مناسبة ونسخ احتياطي لقاعدة البيانات.
